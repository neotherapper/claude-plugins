# Generation Guide: TECH-01 RFC (Request for Comments)

**Purpose:** Propose a significant technical change or decision to the wider team to gather feedback and build consensus.

---

## Prerequisites
- PROD-09 PRD

## Questions to Ask the User
- What is the specific problem or motivation for this change?
- What are the major alternatives you've considered?
- What are the potential drawbacks or risks of the proposed solution?

## Document Template

```markdown
# RFC: [Proposal Title]

**ID:** TECH-01
**Version:** 1.0
**Status:** Draft / In Review / Accepted
**Author:** [Name]
**Created:** [Date]
**Deadline:** [Feedback deadline]

---

## 1. Summary
[One paragraph high-level overview]

## 2. Motivation
- **Problem:** [What's broken or missing?]
- **Goals:** [What success looks like]

## 3. Proposal
[Detailed description of the technical approach]

## 4. Alternatives Considered
| Alternative | Pros | Cons | Why Rejected |
|---|---|---|---|
| | | | |

## 5. Risks & Drawbacks
- [Risk 1] - [Mitigation]

## 6. Open Questions
- [ ] [Unresolved item]
```
