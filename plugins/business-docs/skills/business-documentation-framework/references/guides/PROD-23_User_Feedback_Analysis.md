# Generation Guide: PROD-23 User Feedback Analysis

**Purpose:** Categorize and synthesize raw user feedback into actionable product insights.

---

## Prerequisites
- PROD-22 Release Notes (for post-release feedback)

## Questions to Ask the User
- What are the recurring themes in recent feedback?
- Which pain points are mentioned most frequently?
- What is the general sentiment (1-10)?

## Document Template

```markdown
# User Feedback Analysis

**ID:** PROD-23
**Version:** 1.0
**Status:** Draft
**Created:** [Date]
**Dependencies:** None
**Gateway:** No

---

## Themes

- **Frequency:** [High/Med/Low]
- **Action:** [Ignore/Fix/Prioritize]

## Top Feature Requests
```
