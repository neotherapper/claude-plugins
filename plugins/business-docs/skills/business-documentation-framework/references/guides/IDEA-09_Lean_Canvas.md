# Generation Guide: IDEA-09 Lean Canvas (GATEWAY)

**Purpose:** Synthesize the entire business model on one page to validate the viability of the venture.

---

## Prerequisites
- IDEA-08 Value Proposition Canvas
- IDEA-04 Problem Statement

## Extraction from IDEA-04/08
- Problem list
- Customer segments
- Unique Value Proposition
- Solution features (mapped to pains/gains)

## Questions to Ask the User
- Who are your early adopters specifically?
- What 1-3 metrics tell you if this is working?
- What is your unfair advantage (something hard to copy)?
- How will you generate revenue?
