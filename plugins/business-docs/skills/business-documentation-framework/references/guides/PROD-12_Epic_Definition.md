# Generation Guide: PROD-12 Epic Definition

**Purpose:** Group related user stories into a larger body of work representing a significant feature or initiative.

---

## Prerequisites
- PROD-09 PRD

## Questions to Ask the User
- What is the overarching goal of this epic?
- What is the expected user value once this epic is complete?
- What are the major milestones or phases?

## Document Template

```markdown
# Epic: [Epic Name]

**ID:** PROD-12
**Version:** 1.0
**Status:** Draft
**Created:** [Date]
**Dependencies:** PROD-09
**Gateway:** No

---

## 1. Overview
[Brief description of the initiative]

## 2. Objectives
- [Objective 1]
- [Objective 2]

## 3. User Value
[How this improves the user's life/work]

## 4. Scope (High Level)
- [Feature Group 1]
- [Feature Group 2]

## 5. Related Stories
- US-______: [Name]
- US-______: [Name]
```
