# Generation Guide: PROD-08 Kano Analysis

**Purpose:** Classify features by how they affect customer satisfaction (Must-be, Performance, Delighters).

---

## Prerequisites
- PROD-03 Personas

## Questions to Ask the User
- Which features do users take for granted (Must-be)?
- Which features provide more satisfaction as they improve (Performance)?
- Which features would surprise and delight users?
