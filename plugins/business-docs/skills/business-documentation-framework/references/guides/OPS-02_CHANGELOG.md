# Generation Guide: OPS-02 CHANGELOG

**Purpose:** Document a chronological record of all notable changes to the project, intended for users and maintainers.

---

## Prerequisites
- Release Plan or Git History

## Questions to Ask the User
- What is the new version number?
- What are the major "Added", "Changed", and "Fixed" items?
- Are there any breaking changes?

## Document Template

```markdown
# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [Unreleased]

## [X.X.X] - YYYY-MM-DD

### Added
- [New feature 1]

### Changed
- [Update 1]

### Fixed
- [Bug fix 1]

### Removed
- [Deprecated feature 1]
```
