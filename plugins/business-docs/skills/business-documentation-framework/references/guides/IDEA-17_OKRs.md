# Generation Guide: IDEA-17 OKRs

**Purpose:** Set measurable objectives and key results to align the team during execution.

---

## Prerequisites
- IDEA-09 Lean Canvas

## Questions to Ask the User
- What is the most important goal for the next 3 months?
- How will you know if you've succeeded (quantified)?
- Which team member owns which result?

## Document Template

```markdown
# OKRs: [Period]

**ID:** IDEA-17
**Version:** 1.0
**Status:** Draft
**Created:** [Date]
**Dependencies:** IDEA-09
**Gateway:** No

---

## Objective 1: [Qualitative, Inspirational Goal]
- **KR 1.1:** [Measurable Result] (Target: X)
- **KR 1.2:** [Measurable Result] (Target: Y)

## Objective 2: ...

## Alignment
- **Strategic Fit:** [How this achieves the Mission]
```
