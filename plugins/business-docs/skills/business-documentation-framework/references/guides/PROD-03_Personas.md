# Generation Guide: PROD-03 Personas

**Purpose:** Create detailed user profiles to drive empathy and ensure features solve real needs.

---

## Prerequisites
- IDEA-02 JTBD Analysis

## Questions to Ask the User
- Who is your primary user role?
- What are their daily frustrations related to the problem?
- What technology stack or tools do they currently use?

## Document Template

```markdown
# Persona: [Name]

**ID:** PROD-03
**Version:** 1.0
**Status:** Draft
**Created:** [Date]
**Dependencies:** IDEA-02
**Gateway:** No

---

## Profile
- **Role:** [Job title]
- **Context:** [Work environment]
- **Tech Savvy:** [1-10]

## Goals & Motivations
- [Goal 1]
- [Goal 2]

## Pain Points
- [Frustration 1]
- [Frustration 2]

## Core Job
> When [situation], I want to [motivation], so I can [expected outcome].

## Anti-Goals
- [What this user HATES or avoids]
```
