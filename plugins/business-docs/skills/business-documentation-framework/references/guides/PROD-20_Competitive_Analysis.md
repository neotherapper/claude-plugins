# Generation Guide: PROD-20 Competitive Analysis

**Purpose:** Perform a detailed feature-by-feature comparison against competitors to identify gaps and differentiation.

---

## Prerequisites
- IDEA-14 Competitive Positioning

## Questions to Ask the User
- Who are your 3 most direct competitors?
- Which specific features do they excel at?
- Which features do you have that they lack?
