# Generation Guide: IDEA-19 Feasibility Assessment (GATEWAY)

**Purpose:** Evaluate the technical, market, operational, and financial viability of the project to gate execution.

## Prerequisites
- IDEA-09 Lean Canvas

## Questions to Ask the User
- What specific technical capabilities does this require?
- What is your budget and realistic timeline?
- Have you considered buying an off-the-shelf solution vs building?
