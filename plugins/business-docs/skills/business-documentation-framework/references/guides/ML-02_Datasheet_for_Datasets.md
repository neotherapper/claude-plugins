# Generation Guide: ML-02 Datasheet for Datasets

**Purpose:** Document the origin, composition, and collection process of datasets used for machine learning to ensure data integrity and transparency.

---

## Prerequisites
- Data Collection process complete

## Questions to Ask the User
- Why was this dataset created?
- What do the instances represent (People, Images, Transactions)?
- How was the data collected and validated?

## Document Template

```markdown
# Datasheet: [Dataset Name]

**ID:** ML-02
**Date:** [Date]

---

## 1. Motivation
- **Purpose:** [Why was this created?]
- **Funding:** [Entity]

## 2. Composition
- **Instances:** [What are the rows?]
- **Count:** [Total N]
- **Missing Data:** [Handling method]

## 3. Collection Process
- **Mechanism:** [e.g., Scraping, Survey]
- **Timeframe:** [Dates]
- **Consent:** [Legal basis]

## 4. Recommended Use
- **Tasks:** [Suitable tasks]
- **Restrictions:** [Unsuitable tasks]
```
