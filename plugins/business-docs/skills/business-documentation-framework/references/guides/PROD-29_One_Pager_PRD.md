# Generation Guide: PROD-29 One-Pager PRD (Internal Tools)

**Purpose:** Provide a streamlined requirements document for internal tools where heavy documentation is unnecessary.

---

## Prerequisites
- IDEA-19 Feasibility Assessment

## Questions to Ask the User
- What internal pain point does this solve?
- Who on the team will use it most?
- What are the 3-5 non-negotiable features?

## Document Template

```markdown
# One-Pager PRD: [Tool Name]

**ID:** PROD-29
**Version:** 1.0
**Status:** Draft
**Created:** [Date]
**Dependencies:** IDEA-19
**Gateway:** No

---

## Problem Statement
[2-3 sentences on the pain point]

## Success Metrics
- [Metric 1]
- [Metric 2]

## Core Requirements
1. [Must Have]
2. [Must Have]

## Timeline
- **Start:** [Date]
- **Live:** [Date]
```
