# Generation Guide: PROD-26 MVP Scope Definition

**Purpose:** Explicitly define the boundary of the MVP to prevent scope creep during development.

---

## Prerequisites
- PROD-17 MVP Canvas

## Questions to Ask the User
- Which P0 requirements are the ABSOLUTE minimum?
- What features are you explicitly DEFERRING to Phase 2?
- What are the non-negotiable success signals for the MVP?

```markdown
**Version:** 1.0

**Dependencies:** PROD-17
**Gateway:** No

- [Feature B]

## OUT OF SCOPE (Deferred)

- [Performance target]
- [Security standard]
```
